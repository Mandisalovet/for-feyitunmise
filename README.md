# For Feyitunmise 💜

A playful, purple-themed gift picker for GitHub Pages. Each round gives Feyitunmise 15 seconds to memorise the options, then the tiles shuffle and hide their labels. He chooses one mystery tile per round, and the app reveals the gift, matching treat, and final affection choice.

## Play locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Publish with GitHub Pages
1. Create a new repository on GitHub (for example, `for-feyitunmise`).
2. Upload `index.html` and `README.md` to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish. Your site URL will appear on the Pages settings screen.

The app is static and mobile-friendly; no API keys or server are needed.
