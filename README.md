# For Feyitunmise 💜

A small interactive surprise I made for my boyfriend, Feyitunmise. I wanted to turn choosing a gift into a playful little game instead of simply telling him what he might get. The app uses a purple theme because purple is his favourite colour.

## About the project

The game has three rounds. In each round, Feyitunmise gets 15 seconds to look at the options before the tiles shuffle and hide their labels. He then picks one mystery tile. His choices are revealed at the end as one combined surprise.

### Round 1 — Main gift
- Manchester United jersey (2025)
- Manchester United jersey (2026)
- R1,000 PlayStation gift card

### Round 2 — A matching treat
The treat options depend on the main gift selected:

- **2025 jersey:** KFC, Burger King, McDonald's, Nando's and Steers
- **2026 jersey:** chocolate, Coke, Schweppes, Doritos and Astros
- **PlayStation gift card:** Wedgewood ice cream, Paul's Homemade Ice Cream, Yogurtland and Cinnabon

### Round 3 — One final choice
- Kiss 💋
- Hug 🫂
- High five 🙌
- Handshake 🤝

At the end, the app reveals the three selected options together with a celebratory message.

## Built with

- **HTML** for the app's structure
- **CSS** for the purple theme, layout and tile animations
- **JavaScript** for the countdowns, shuffling, selections and final reveal

The project is a static website: it does not need a backend, API keys, or a package installation. It is designed to work in a web browser on a phone or computer.

## Run it locally

1. Download or clone this repository.
2. Open `index.html` in a browser.
3. Play through the rounds and try the surprise reveal.

No build step is required.

## Publish with GitHub Pages

1. Create a GitHub repository, for example `for-feyitunmise`.
2. Add `index.html` and `README.md` to the repository's root directory.
3. Open the repository's **Settings** and select **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/(root)` folder, then save.
6. Wait for GitHub Pages to finish publishing. The public site URL will appear in the Pages settings.

## What I wanted to practise

I used this project to bring together a few front-end ideas in one personal project: timed rounds, interactive mystery tiles, conditional options, simple animations and a final results screen. It was also a fun way to make something personal rather than building a generic demo.
